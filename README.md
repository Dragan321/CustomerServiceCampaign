## How to Use

1. **Register a user**  
   Navigate to:  
   `http://localhost:5134/scalar/v1#tag/users/POST/users/register`

2. **Obtain an access token**  
   Send a request using the file:  
   `CustomerServiceCampaign.Login.http`

3. **Access the API via Scalar UI**  
   Use the obtained token in the Scalar UI to call protected endpoints.
